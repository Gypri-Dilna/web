Mode: **After**. Scope: the whimsy pass, which raised the dials to

## What the pass changed

Before this pass the site read as bland and corporate. The cause was assets, not CSS:
it had one screenshot, three generic tool pictograms, and thumbnails from an old
WordPress page. The workshop's own archive of 232 photographs was reviewed and
20 were selected. That, plus one warm colour, is the whole fix.

Added: real photography throughout, an orange accent taken from the Gypri whistles
the workshop prints, tilted photo frames, an eyebrow tick, a rule under each section
heading that draws itself in, a ruler-tick divider, a chip, and a turning logo.

Dials moved: ENERGY 2 to 3, RHYTHM 2 to 3, MOTION 1 to 2. All recorded in `DESIGN.md`.

## Findings from the detector

### 1. `marquee` (warning): FIXED by removal

I built an auto-scrolling band of the workshop's disciplines: 3D tisk, Robotika,
Elektronika, Pájení, Programování, CNC, Bastlení.

The detector's objection was right, and for a reason I should have caught before
building it: **the same four words are already listed in the section immediately
below it**. The band repeated existing content, so the motion carried no information.
That is the definition of attention that has not been earned. It also hid half its
own content at any moment, and it demanded a pause-on-hover affordance to be usable.

A marquee is also the single most recognisable "make it feel fun" move, which is
exactly the kind of default this whole process exists to catch. The genuine whimsy on
this site is the photography: students crowded around a PC build, an orange whistle in
the palm of a hand. That does not need a moving band next to it.

Removed: the markup, the CSS block, the keyframes, the reduced-motion rules, and the
type-scale row. Nothing replaced it.

### 2. `repeating-stripes-gradient` (advisory): FIXED by redrawing

The tick divider used `repeating-linear-gradient` to draw ruler ticks.

The rule asks for "a deliberate texture" rather than a gradient stripe, and it is
right that a repeating gradient is the generic way to get this look. But the ruler
itself is a real idea: a bench is ruled and measured, and this is the site's identity
motif after the hex-nut chain was cut for repeating the logo too literally.

So rather than delete the element, I redrew it as an explicit inline SVG tick, plus a
hairline and one orange measured mark. The intent is now in the code as a drawn tick
instead of a gradient, which is the deliberate version the rule asks for.

## One bug this pass introduced and fixed

The whimsy rewrite replaced the block that held `.js .reveal`, so the reveal CSS
vanished while `main.js` still added `.is-visible`. Separately, the head script that
sets the `.js` class had been missing since the antislop pass, so the reveal rules were
inert. Both are fixed, and verification now asserts:
the `.js` class is set before `</head>`, `.js .reveal` exists, `main.js` observes both
`.reveal` and `.section-head`, and reduced motion forces reveals visible.

## Follow-up, same day: the second accent was wrong

A second accent was added in this pass, Whistle Orange `#ff6b35`, on the reasoning that
the workshop's orange products made it brand evidence. That was wrong on both counts and
it has been removed.

**Why it was wrong.** The brand guide names three colours: Graphite Core, Circuit Mint and
Cloud Paper. Orange is a *product* colour, not a brand colour. The antislop pass had
already established a one-accent rule for this site, and this document recorded it. Adding
a second accent silently overrode a decision that had been made deliberately, in response
to a request ("less bland") that was about liveliness, not about palette.

**What replaced it.** Every gesture that used orange now draws in Circuit Mint: the eyebrow
tick, the rule under each section heading, the key-phrase underline, the ruler mark, and
the callout label. `label-orange` was renamed `label-accent`. The hero scrim lost its warm
tint and is now plain dark, which also stops a colour cast fighting the yellow building in
the photograph. The `.whistle-note` callout lost its orange border and wash and is now a
neutral raised surface, and becomes the rule-consistent `.callout`.

**The underline was also rebuilt.** It was a solid colour bar painted behind the words,
which lowered the contrast of the glyphs sitting on it and could not wrap, so a long marked
phrase was clipped off-screen on mobile. It is now a `text-decoration` underline: it draws
below the baseline, so it never touches text contrast, and it breaks across lines like
normal text. Measured: `scrollWidth` on cansat.html at 390px went from 676 to 390.

## Two more bugs found while checking this, both real

**1. `.feature-item` squeezed its text into a 34px column.** The element was a two-column
grid (`34px 1fr`) from when each item carried a pictogram beside its text. The pictograms
were deleted in favour of real photographs, but the grid column stayed, so the copy was
rendered one word per line. Visible in a screenshot, invisible to every automated check I
had. Fixed by removing the grid, and the now-redundant wrapper `<div>`s came out of the
markup too.

**2. The earlier mobile check was too narrow.** I had verified mobile on `index.html` only.
The clipped underline was worst on `cansat.html`, whose marked phrase is far longer. The
lesson is in the verification now: all five pages are checked at 320, 390 and 768px.

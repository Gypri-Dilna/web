# antislop audit 001, 2026-09-10

Mode: **After** (audit of finished work). Ruleset: antislop core v3.x + `antislop-ui` + `antislop-copywriting`.
Scope: the five site pages, `styles.css`, `main.js`, `README.md`.
Nothing has been modified. Numbers not approved are not touched.

Direction check (R-37): **PASS**. `DESIGN.md` as such does not exist, but explicit brand
direction does: *Dilna Logo - brand guide.pdf* ("Návod Brand 2025") fixes the palette
(Graphite Core / Circuit Mint / Cloud Paper), the typeface (Montserrat), and the logo
concept. This is not a "draft without direction"; the direction is real and was applied.

## Findings

### HIGH (Hard Gate)

**1. R-02: em dash character appears 29 times across all five pages.**
Absolute ban, outside the documentation carve-out. Affects `<title>` tags, meta
descriptions, and visible body copy. Extra: `README.md` has 8 more. (The git commit
message is clean, 0.)

**2. R-38: `kontakt.html` invents opening hours and presents them as fact.**
The "Otevírací doba" block says the workshop is open "v rámci technického kroužku a po
domluvě" and that it is best to write ahead. No source states any opening hours. This is
fabricated content dressed as real, in a section whose entire purpose is factual. The
README flags it, but the page itself does not.

**3. R-17: `index.html:120` uses `&infin;` as a value inside a data block.**
`Nářadí a CNC / ∞` sits in the same `.data-val` treatment as the real counts (07 printers,
07 notebooks, 01 PC). A data block implies sourced data; an infinity symbol is decoration
posing as a statistic. Either give the real number of tools or drop the block.

**4. R-35: no recorded element-by-element click-through exists.**
Verification so far covers images, overflow, console, and axe (all clean), and the mobile
menu was toggled. But R-35 requires every interactive element exercised one at a time with
its result recorded as evidence in the report. That artifact is missing. Needs to be run
and recorded before this can be called delivered.

### MEDIUM (Purpose-Gate: technique allowed, written reason required)

**5. R-01: two radial gradients in `.glow` (styles.css:160-161) form a background orb.**
"Blurred radial orbs behind the hero" is the named default in Part 1. The colour is
brand-derived, so it is not the blue-purple tell, but no hierarchy or identity purpose is
stated anywhere.

**6. R-07: four decorative background layers stack on every page.**
`#ambience` (drifting hex glyphs on canvas), `.noise` (feTurbulence texture), `.hud-frame`
(two full-height hairline rules plus four corner ticks), `.divider-glyphs` (repeated hex
chain). Part 1 calls this out directly under trend-stacking. Each layer needs a one-line
reason or removal.

**7. R-06: wide-tracked uppercase is used 33 times in `styles.css`.**
`.hud-label` and `.eyebrow` run 0.24em tracking, `.data-label` 0.22em, `.nav a` 0.2em,
plus `.tech-title`, `.timeline-date`, `.contact-row-mega span`, `.idx`. "Uppercase labels
with extreme letter-spacing" is the named tell. The HUD language was explicitly requested,
so the fix is dose, not removal, and the reason needs writing down.

**8. R-14: three sections use three identical feature cards.**
`index.html` "Co u nás děláme", `cansat.html` "Jak soutěž probíhá", `nase-prace.html`
"Speciální komponenty". All `.panel--feature`, identical size, padding, layout, and all
three carry an icon. `cansat.html` additionally matches the "How It Works always in 3
steps" shape. `index.html` repeats the treatment with a 4-card grid.

**9. R-19: motion runs on everything, including an endless loop.**
`.reveal` fade-up is applied to all 59 blocks (template animation on every element),
`.media:hover img` adds scale, and `#ambience` animates forever with no user trigger, which
the UI skill names as noise. The MOTION dial was never declared, so none of this can be
checked against it.

**10. R-13 / R-29: the accent is spread across nearly every surface.**
Mint appears on body links, buttons, button borders, section indices, eyebrows, timeline
dates, tech titles, accent data values, the active-nav underline, the divider rule, the
background glow, the canvas strokes, text selection, and the focus outline. Part 3:
"Zero accents is sterile; an accent everywhere is slop."

**11. R-05: uniform section rhythm on `index.html`.**
All five sections follow the same composition: `.section-head` (`[ 0N ]` + `h2`) then a
grid. With RHYTHM undeclared, this cannot be defended as a deliberate choice.

### LOW (Quality Locks)

**12. R-08: `↗` is on every external link.**
Access System (nav, footer, contact row), Instagram, ikaroscansat.cz, ground station. It
consistently marks off-site destinations, which is a real convention, but the purpose is
not written down.

**13. R-05: footer is close to the template shape.**
Three columns (brand blurb, "Odkazy", "Kontakt"). Not the four-column default, but still a
template silhouette rather than one derived from what the site actually links to.

**14. R-31: no written reason for major decisions.**
`README.md` records where the palette came from but not why this layout, why this spacing,
or why cards. The keystone rule asks for one line per major decision.

**15. R-21: dark theme is the default.**
Defensible, since the IKAROS reference was explicitly requested and school technical
workspaces suit dark. But the brand guide describes Cloud Paper as the base that
"zajišťuje lehkost a čitelnost", so the choice should be recorded as deliberate, or a
light/dark toggle built.

## Block 3 (Liveliness) status

ENERGY / RHYTHM / MOTION were never set, so findings 9 and 11 cannot be judged against a
declared target. Block 3 requires all seven of its answers to be yes; this one is
currently no. It is a gate failure independent of the rules above.

## Summary

16 findings: 4 HIGH, 7 MEDIUM, 4 LOW, plus 1 gate failure (dials).

The floor is solid: accessibility, keyboard use, contrast, mobile, navigation, and identity
all pass, and the direction is real rather than invented. The slop is concentrated in three
places: the em dash ban, one invented fact, and decoration stacked past its dose (findings
5, 6, 9, 10 are one underlying problem: effects applied everywhere instead of at one
focal point).

Suggested minimum to ship: **1, 2, 3, 4, 16**. Those are the gate blockers.
